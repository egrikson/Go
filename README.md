# Go — практика по курсу metanit

Репозиторий с решениями практических заданий по ходу изучения Go.

**Теория:** [Руководство по языку Go — metanit.com](https://metanit.com/go/tutorial/1.1.php)
**Конспекты:** ведутся отдельно в Obsidian, в репозиторий не входят.

## Как устроено

Один модуль `gostudy` на весь репозиторий. Каждое задание — отдельная папка с `package main`, сгруппированы по главам курса:

```
ch02/
  2.7/
    task1/main.go
    task2/main.go
```

Запуск конкретного задания:

```bash
go run ./ch02/2.7/task1
```

Порядок работы и правила выдачи заданий описаны в [CLAUDE.md](CLAUDE.md).
