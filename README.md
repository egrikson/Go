# Go — практика

Репозиторий с решениями практических заданий по ходу изучения Go.

- **Цель:** стажировка по направлению Go + портфолио.
- **План:** с 09.09.2026 обучение идёт по собственному роадмапу (блоки: база языка → интерфейсы и ошибки → стандартная библиотека и тесты → PostgreSQL → HTTP → Docker → конкурентность). План и конспекты ведутся в Obsidian, в репозиторий не входят.
- **Теория:** курс [metanit](https://metanit.com/go/tutorial/1.1.php) закрывается на главе 2 и дальше используется только как справочник по синтаксису. Основные источники — [Tour of Go](https://go.dev/tour/), [Learn Go with Tests](https://quii.gitbook.io/learn-go-with-tests), [Go by Example](https://gobyexample.com/).

## Как устроено

Один модуль `gostudy` на весь репозиторий. Каждое задание — отдельная папка с `package main`. Задачи по metanit сгруппированы по главам курса (`ch01`, `ch02`), дальнейшие — по блокам плана (`block01` и далее):

```
ch02/
  2.4/
    task1/main.go
    task2/main.go
```

Условие задачи лежит в комментарии в начале файла, там же — команда запуска.

Запуск конкретного задания:

```bash
go run ./ch02/2.4/task1
```

Порядок работы и правила выдачи заданий описаны в [CLAUDE.md](CLAUDE.md).
