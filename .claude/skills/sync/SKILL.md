---
name: sync
description: Зафиксировать прогресс по Go одной командой — проверить изменённые задачи, обновить README и прогресс в Obsidian, закоммитить и запушить. Использовать, когда пользователь пишет /sync, «сохрани прогресс», «закоммить и отпуш», «закоммить, обнови README и конспекты».
---

Запусти агента `go-sync` через инструмент Agent:

- `subagent_type: "go-sync"`;
- `run_in_background: false` — пользователь ждёт результат;
- в `prompt` передай: «Зафиксируй прогресс в репозитории по своей инструкции.» и, если пользователь что-то уточнил в команде (например, «только README» или «задачу 2 не трогай»), — добавь это дословно.

Сам шаги агента не повторяй и параллельно ничего не правь.

Когда агент закончит, его отчёт пользователь не видит — перескажи его полностью: коммиты (хеш, сообщение, запушено ли), статус каждой задачи, что изменено в README и Obsidian, что осталось сделать. Если агент остановился («Когда остановиться»), объясни почему и что предлагается.
